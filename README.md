# China Landed Cost

Калькулятор полных затрат (landed cost) на поставку негорючего акустического наполнителя из Китая в РФ.

## Возможности

- **Закупка** — ввод параметров товара: поставщик, HS-код, цена в юанях, пошлина, НДС
- **Логистика** — сравнение ставок экспедиторов (ИГЛ, Галеос, Дельпорте, порт Циндао) по маршрутам Китай → Серпухов / Ставрополь
- **Ландед-кост** — итоговый расчёт: продукт + пошлина + фрахт + автовывоз + НДС → ₽/м² и ₽/кг

## Стек

React 19 · TypeScript · Vite · Tailwind CSS · SheetJS (xlsx) · lucide-react

## Запуск

```bash
npm install
npm run dev
```

## Табы

1. Сравнение ставок — импорт/ввод котировок перевозчиков
2. Схемы маршрутов
3. Итоговый отчёт
4. Аналитика
5. **Земля + Логистика** — расчёт полных затрат
