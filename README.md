# China Landed Cost

Калькулятор полных затрат (landed cost) на поставку негорючего акустического наполнителя из Китая в РФ.

## Возможности

- **Закупка** — ввод параметров товара: поставщик, HS-код, цена в юанях, пошлина, НДС
- **HS-код** — проверка формата (10 цифр), справочник кодов со ставками пошлины, подстановка ставки в расчёт по кнопке
- **Курс ЦБ на дату** — подтягивается на выбранную дату расчёта, кэшируется в браузере, в шапке видно фактическую дату курса
- **Логистика** — сравнение ставок экспедиторов (ИГЛ, Галеос, Дельпорте, порт Циндао) по маршрутам Китай → Серпухов / Ставрополь
- **Себестоимость** — основной сценарий: товар и параметры → выбор маршрута → итог в ₽/м² и ₽/кг
- **Дополнительные расходы** — отдельный блок (агентское вознаграждение, покупка валюты и позиции ТЭО: сбор за контейнер, релиз-ордер, хранение, сверхнорма, досмотр, ЖД-приём, мониторинг, обработка). Суммы вводятся как в счёте (с НДС), прибавляются к итогу, но не входят в таможенную базу — пошлина и импортный НДС от них не растут. НДС-переключатель у статьи выделяет из суммы его часть для отчёта. Состав и суммы сохраняются в браузере и подставляются в следующий расчёт; можно добавить и удалить свою статью
- **Отчёт** — сводка на дату согласования, копирование текста и выгрузка полного расчёта в Excel (поставщик, HS-код, все варианты маршрутов)
- Импортный НДС рассчитывается по ставке товара с базы «товар + фрахт + пошлина»; НДС на российские услуги — отдельно по ставке выбранного перевозчика
- Дополнительные параметры товара (объём, вес, пошлина и НДС) скрыты до необходимости
- Если ставки ещё не загружены, их можно добавить тремя способами прямо из основного сценария: вставить текст КП, загрузить Excel/JSON или ввести вручную (форма из 3 шагов)
- Остальные вкладки доступны для управления ставками, просмотра схем маршрутов, отчёта и аналитики

## Стек

React 19 · TypeScript · Vite · Tailwind CSS · SheetJS (xlsx) · lucide-react

## Запуск

```bash
npm install
npm run dev
```

Новый запуск открывает сценарий расчёта себестоимости. В форме предварительно заполнены параметры акустического товара; перед использованием их следует сверить с инвойсом и условиями конкретной поставки.

## Курс ЦБ РФ на дату

Курс тянется из браузера напрямую с зеркала `cbr-xml-daily.ru` — оно отдаёт CORS-заголовки (`Access-Control-Allow-Origin: *`), поэтому прокси-сервер не нужен (прежний прокси на Vercel больше не используется). Для сбоя/отсутствия сети в коде оставлено несколько уровней фолбэка.

Курс запрашивается на дату расчёта и кладётся в `localStorage` (`logistics_cbr_cache_v1`). На сегодня/будущее берётся текущий опубликованный курс (`daily_json.js`); на прошедшую дату — архив по дате, при промахе (выходные/праздники) отступаем назад до ближайшего торгового дня (до 6 дней). Для прошедших дат кэш считается вечным (курс уже не изменится), для текущей — обновляется раз в 6 часов. Если сеть недоступна, берётся последний сохранённый курс, а в шапке появляется пометка «кэш». Фактическая дата курса показывается в шапке и в блоке себестоимости.

## HS-коды и пошлина

Код проверяется на 10 цифр и нормализуется (пробелы не важны). Справочник (`src/data/hsCodes.ts`) содержит рабочие коды со ставками: 8708299000 (12%), 7604210000 и 7604109000 для алюминиевых профилей (12%, лист «брокер» калькулятора КНР). Свои коды можно сохранить из формы — они хранятся в `localStorage` (`logistics_hs_codes_v1`) и попадают в экспорт настроек.

Ставка пошлины подставляется в расчёт только по явному нажатию «Применить», а не автоматически. Если ставка по коду неизвестна (`dutyRate: null`), калькулятор её не выдумывает: код помечается как «ставка не задана», и её нужно подтвердить у брокера. Итоговый код и ставку перед декларацией всегда проверяет таможенный брокер.

## Полный отчёт в Excel

Кнопка «Скачать отчёт Excel» (в блоке себестоимости и в сводном отчёте) выгружает книгу из пяти листов:

1. **Сводка** — дата расчёта, курс ЦБ и его фактическая дата, поставщик, HS-код и наименование по коду, ставка пошлины и НДС, параметры товара, лучшие варианты по складам и выбранный маршрут;
2. **Маршруты** — каждое предложение экспедитора отдельной строкой: схема, срок, фрахт, Ж/Д, автовывоз, комиссия, терминал, перевес, НДС услуг, итог логистики, продукт, пошлина, импортный НДС, ландед-кост, ₽/м², ₽/кг и место по цене;
3. **Выбранный маршрут** — построчная расшифровка сумм и ₽/м² с пояснением формул;
4. **Исходные ставки** — введённые значения с валютами, ставками НДС и сроком действия (для проверки);
5. **Методика** — формулы расчёта и ограничения.

В ландед-кост входит доплата за перевес сверх тоннажа, включённого в ставку перевозчика (округление вверх до целой тонны), и НДС на неё — по ставке перевозчика.

## Загрузка ставок перевозчиков

Три равнозначных входа (кнопки-карточки в основном сценарии и кнопка «Текст КП» в управлении ставками):

1. **Вставить текст КП** — письмо или сообщение из мессенджера вставляется как есть в одно поле. Текст разбирается автоматически (блок за ~350 мс): перевозчик (в т.ч. из строки-шапки «ООО …» перед таблицей), склад, порт, тип маршрута, пять статей затрат с валютой, срок, контейнер, вес, перевес, НДС и дата действия ставки. Всё распознанное показывается карточками для правки прямо в окне, спорные места помечены подсказками, исходный фрагмент доступен для сверки. В примере — два маршрута разных схем в одном письме. Добавляется одной кнопкой «Добавить N ставок».
2. **Загрузить файл** — Excel или JSON. Распознаются: наша форма запроса цен (по заголовкам колонок), файлы перевозчиков с понятными колонками и JSON из приложения. В окне загрузки — ссылка на скачивание заполненного примера и пустой формы для перевозчика. До импорта показывается предпросмотр с валидацией.
3. **Ввести вручную** — форма из трёх шагов: маршрут (перевозчик с автодополнением, склад, порт, тип маршрута) → пять сумм с валютой и живым итогом → срок, контейнер и свёрнутые дополнительные параметры (вес, перевес, НДС, срок действия — по умолчанию сегодня + 30 дней). Кнопка «+ Ещё маршрут» сохраняет перевозчика и открывает ввод новых сумм.

Все импортированные и вручную добавленные ставки попадают в историю снимков («История») и сравниваются с предыдущим снимком — изменения подсвечиваются в уведомлениях.
